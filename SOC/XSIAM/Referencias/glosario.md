# Glosario

| Término | Definición sencilla |
|---|---|
| Alert | Señal generada por una detección que requiere revisión o contexto. |
| Case | Contenedor de investigación con alertas, evidencias, tareas y notas. |
| Incident | Evento de seguridad gestionado formalmente por posible o confirmado impacto. |
| Dataset | Conjunto de datos consultable con XQL. |
| Preset | Vista preparada para consultar ciertos datos o campos de forma más cómoda. |
| XQL | Lenguaje de consulta para buscar, filtrar y correlacionar datos en Cortex. |
| Playbook | Flujo automatizado o semiautomatizado para investigar, enriquecer, notificar o responder. |
| Webhook | URL HTTP que recibe datos enviados por otra aplicación. |
| IOC | Indicator of Compromise. Indicador como IP, hash, dominio o URL asociado a actividad sospechosa. |
| MITRE ATT&CK | Marco de conocimiento de técnicas y tácticas usadas por adversarios. |
| False Positive | Alerta que no representa actividad maliciosa o riesgo real en su contexto. |
| True Positive | Alerta confirmada como actividad maliciosa o relevante para respuesta. |
| Severity | Nivel de gravedad o prioridad estimada de una alerta. |
| Enrichment | Añadir contexto a una alerta, como reputación, criticidad de asset o información de usuario. |
