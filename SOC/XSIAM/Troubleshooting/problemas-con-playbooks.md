# Problemas con playbooks

## Checklist

- [ ] Trigger correcto.
- [ ] Playbook habilitado.
- [ ] Integraciones conectadas.
- [ ] Credenciales vigentes.
- [ ] Permisos suficientes.
- [ ] Inputs disponibles.
- [ ] Outputs esperados revisados.
- [ ] Branches con condiciones correctas.
- [ ] Errores registrados en tareas.
- [ ] Cambios recientes revisados.

## Problemas frecuentes

| Problema | Causa habitual |
|---|---|
| No se ejecuta | Trigger mal definido o playbook deshabilitado. |
| Falla una tarea | Integración, permisos o payload. |
| Rama incorrecta | Campo vacío o condición mal evaluada. |
| Notifica demasiado | Falta control por severidad o duplicados. |
