# Qué es Cortex XSIAM

Cortex XSIAM es una plataforma de operaciones de seguridad que combina capacidades de SIEM, XDR, automatización, análisis, gestión de alertas y gestión de casos/incidentes.

En palabras simples: ayuda a centralizar datos de seguridad, detectar actividad sospechosa, investigar eventos y coordinar la respuesta desde un mismo entorno.

> [!NOTE]
> Para un analista SOC: XSIAM es el lugar donde revisas señales, entiendes el contexto, consultas datos con XQL y decides si una alerta es True Positive o False Positive.

## Capacidades principales

| Capacidad | Explicación sencilla |
|---|---|
| Ingesta de datos | Recibe logs, eventos y telemetría desde endpoints, identidades, cloud, red y otras fuentes. |
| Normalización | Organiza datos de distintas fuentes para poder consultarlos y correlacionarlos. |
| Detección | Genera alertas a partir de reglas, analítica, modelos y contenido de seguridad. |
| Investigación | Permite consultar datos con XQL y navegar entidades como usuarios, hosts e IPs. |
| Automatización | Ejecuta acciones mediante playbooks, integraciones y scripts. |
| Gestión de casos | Agrupa alertas y evidencias para seguimiento y cierre. |

## Qué problema resuelve

Un SOC suele tener demasiados datos, demasiadas alertas y poco tiempo. XSIAM busca reducir ruido, agrupar señales relacionadas y permitir que el analista trabaje con contexto.

## Nota para usuario no técnico

XSIAM no es solo una herramienta de alertas. Es una consola de trabajo para que el equipo de seguridad vea qué pasó, qué equipos o usuarios están afectados, qué riesgo existe y qué acciones se tomaron.
