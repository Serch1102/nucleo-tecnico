# Notificaciones

Una notificación debe avisar sin saturar.

## Campos mínimos recomendados

| Campo | Motivo |
|---|---|
| Severidad | Priorizar. |
| Cliente/tenant | Evitar confusión en MSSP o multi-cliente. |
| Nombre de alerta | Entender la detección. |
| Case/Issue ID | Ir al registro de trabajo. |
| Host | Identificar entidad afectada. |
| Usuario | Contexto de identidad. |
| IP origen/destino | Contexto de red. |
| Resumen | Qué pasó en lenguaje claro. |
| Acción esperada | Qué debe hacer el receptor. |
| Link a XSIAM | Acceso rápido al caso. |

> [!WARNING]
> No incluyas secretos, tokens, credenciales, datos personales innecesarios o información sensible excesiva en canales de chat.
