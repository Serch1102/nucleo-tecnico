# Visión general de integraciones

Las integraciones conectan XSIAM/XSOAR con herramientas externas para enriquecer, notificar o responder.

## Tipos comunes

| Tipo | Ejemplo | Uso |
|---|---|---|
| ChatOps | Microsoft Teams | Notificar alertas y decisiones. |
| Ticketing | ServiceNow, Jira | Crear y seguir tickets. |
| Correo | SMTP/Graph | Notificar a usuarios o clientes. |
| Threat intel | Fuentes IOC | Enriquecimiento. |
| Webhook | HTTP endpoint | Integración simple y desacoplada. |

> [!WARNING]
> Cada integración depende de permisos, credenciales, conectividad, licencia y configuración del tenant.
