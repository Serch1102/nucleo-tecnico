# Ticketing

El ticketing ayuda a dar seguimiento formal a acciones, responsables y tiempos.

## Cuándo abrir ticket

- Requiere acción de otro equipo.
- Hay impacto potencial o confirmado.
- Se necesita evidencia de cumplimiento.
- Se requiere seguimiento más allá del turno SOC.

## Campos recomendados

| Campo | Motivo |
|---|---|
| Case/Incident ID | Trazabilidad. |
| Severidad | Priorización. |
| Entidades afectadas | Equipo, usuario, IP. |
| Evidencias | Sustento técnico. |
| Acción solicitada | Evitar ambigüedad. |
| SLA | Seguimiento. |
