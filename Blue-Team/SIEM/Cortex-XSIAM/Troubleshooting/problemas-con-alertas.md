# Problemas con alertas

## Checklist

- [ ] Confirmar rango temporal correcto.
- [ ] Validar que la fuente de datos está ingiriendo.
- [ ] Revisar permisos del usuario.
- [ ] Confirmar que la alerta no fue agrupada en otro case.
- [ ] Revisar filtros de severidad o estado.
- [ ] Validar cambios recientes en reglas o contenido.
- [ ] Comprobar retención disponible.

## Síntomas comunes

| Síntoma | Posible causa |
|---|---|
| No veo alertas | Filtro, permisos, ingesta o retención. |
| Alertas duplicadas | Regla duplicada, reingesta o varias fuentes. |
| Falta contexto | Campos no mapeados o fuente incompleta. |
